# Guía para una actividad educativa con IA

## Propósito

Definí qué aprendizaje necesita comparación, revisión o producción asistida. La IA no reemplaza el objetivo ni la decisión docente.

## Consigna sugerida

1. Generá una primera respuesta sin incluir datos personales.
2. Contrastala con dos fuentes identificables.
3. Marcá errores, omisiones o sesgos.
4. Elaborá una versión propia y explicá los cambios.

## Criterios

- Calidad de las fuentes.
- Justificación de correcciones.
- Transparencia sobre el uso de IA.
- Claridad del producto final.
